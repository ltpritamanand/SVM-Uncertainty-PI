Notes on sigma2 variants:
  sigma2_raw          : mean per-point variance across 10 runs (original y-units²).
  sigma2_var_norm     : sigma2_raw / var(y_test). Model instability relative
                        to how much the test data itself varies. < 1 → model
                        variance is smaller than data variance — good.
  sigma2_range_norm   : sigma2_raw / range(y_test)². Similar but uses full
                        spread; more sensitive to outliers in the test set.
  Both normalised variants use the specific test-set statistics for each
  data size, making them fair for the sliding test-set protocol.
